# PLAN.md: WoW UI Sim Rendering Optimization

**Goal:** Reduce main-thread CPU cost and interactive latency during panel open/close and idle UI rendering.

## Completed Work

**Profiling & Diagnosis**
- Identified cooldown-scan, texture-warmup, per-rebuild scans, anchor re-renders, layout recomputation, and hit-grid re-ranking as top costs
- Built `bench_steady_state` binary for repeatable single-frame measurements
- Built `bench_spellbook --cycles N` for repeatable panel open/close timings

**Fixes Merged to Master** (not pushed; all tested)
1. Cooldown registry index (`77089bb12`, `3b8a06457`): scan only registered Cooldown IDs instead of every widget. CPU share: 46% → 1%.
2. Asset-resolver listfile cache keying (`3088dee` in asset-resolver, `c3e373f9c` in wow-ui-sim): per-project cache by source path. Fixes shared-cache thrashing.
3. Texture warmup skip (`7535af12e`): skip rescans until strata rebuild. Tick p50: 3.83ms → 1.98ms.
4. Per-rebuild texture scans (`946d8255b`): removed redundant path collection. HashSet insert: 3.5% → 0.13% CPU.
5. Anchor same-value guards (`672c32aab`): `ClearAllPoints`/`SetPoint` skip re-render if rect unchanged. Draw halved relative to tick.
6. Layout de-duplication (`4e64f9e20`): recompute each frame once per pass. Spellbook reopen 18% faster, close 15% faster.
7. Hit-grid one-pass update (`45808d6ab`): process each frame once per batch, skip re-inserts if unchanged. Reopen draw −33%, close draw −49%.
8. Faster hash maps (`c007a2f6b`): Fx instead of Sip on u64 registry keys. ~5–8% less draw.
9. `bench_spellbook --cycles N` (`02cc4185d`): repeatable open/close benchmark.

**Result:** Spellbook panel open went from ~40ms to ~25ms (37% faster), close from ~25ms to ~16ms (36% faster).
