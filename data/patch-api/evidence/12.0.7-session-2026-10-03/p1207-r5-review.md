## 2. Authentication order — every changed producer

### Six C_PartyInfo producers: PASS for the requested all-argument order

`roles_1207.rs:16–27` first iterates the complete call frame: `for value in state.stack.iter().take(state.top).skip(state.base) { unwrap_secret(state, *value)?; }`. ### Macro producer: PASS for argument authentication; incomplete native contract

`spell_macro_verbs.rs:152–163` authenticates all positions/extras, then unwraps text/button, then validates button (unless nil), then text. Only afterward does `run_macro_text` dispatch commands (`:177–188`). Therefore tainted secret extras beat an earlier invalid text value. Required-button nilability and native restrictions remain qualifications above. Conditional marker parser receives an internal Rust string, not unauthenticated Lua arguments; it reads/resolves/validates before calling existing SetRaidTarget (`:218–254`).

### Changed role-query producers: FAIL for complete declaration/security standard

`UnitIsGroupAssistant` and `UnitLeadsAnyGroup` still perform `Option::<String>::from_stack(state, 1)?.unwrap_or_default()` before model access, ignore extras, and push plain booleans (`group_queries_relationships.rs:239–279`). CACHE `Blizzard_APIDocumentationGenerated/UnitDocumentation.lua:1949–1962,2369–2382` declares both `SecretArguments = "AllowedWhenUntainted"` and `SecretWhenUnitIdentityRestricted = true`, with required unit tokens.

This is not an implicit shared guard: `src/lua_bridge/from_stack.rs:42–47,294–325` reads raw stack values; `group_queries.rs:196–205` registers direct Rust closures. Thus securely wrapped unit tokens fail raw string conversion, tainted secret extras are ignored, nil is accepted, and restricted identity outputs remain plain. Concrete static counterexamples: secure `UnitIsGroupAssistant(secretwrap('party1'))` reaches raw string conversion; tainted `UnitIsGroupAssistant('party1', secretExtra)` never checks the extra. Same for UnitLeadsAnyGroup.

**Inherited defect, not introduced by the new branch**, but these are modified producers and are used as public observers of new state. Six namespace guard tests do not discharge these additional boundaries. No INFERRED label in those query producers explains their omitted identity secrecy. Accepting bounded role state must not be reported as accepting every changed producer's secrecy contract.
