## Exact vendor behavior observed

### Spacer
- Retail and PTR registration: visualization type `Spacer`, `UIWidgetTemplateSpacer`, getter above.
- Both getters return the record only when it exists and `shownState ~= Enum.WidgetShownState.Hidden`; otherwise nil.
- `Setup` invokes base setup, then sets width and height. Retail uses `Clamp(widgetWidth, 1, widgetWidth)` and same for height; PTR uses `math.max(value, 1)`.
- XML inherits `UIWidgetBaseTemplate`, virtual frame, initial size 10x10. No custom texture, atlas, or animation prerequisites observed.
- No custom update/reset/unregister methods in the read Lua body. Base manager lifecycle remains uninspected.
- Exact type/field/nullability/secret policy: unresolved without generated documentation/source producer record.

### IconTextAndBackground
- Retail and PTR registration: visualization type `IconTextAndBackground`, `UIWidgetTemplateIconTextAndBackground`, getter above; same nil/hidden filtering.
- `OnLoad` calls base `OnLoad`.
- `Setup` calls base setup, applies `textureKit` to `Icon` (`%s-icon`) and `Glow` (`%s-glow`) using `SetupTextureKitOnRegions(... SetVisibility, UseAtlasSize)`, sets `Text` from `widgetInfo.text`, then calls `Layout()`.
- XML inherits `UIWidgetBaseTemplate, ResizeLayoutFrame`; minimum width 100. `Icon` atlas-sized at top-left; `Glow` atlas-sized, ignored in layout and anchored left of Icon by 25; `Text` is centered on Glow using `GameFontNormalSmall`. No explicit animation/update/reset/unregister in this mixin.
- Minimal demonstrated prerequisites: existing atlas-kit application/visibility and atlas-size handling; text `SetText`; resize-layout `Layout`; base widget lifecycle; regions and font template. Do not invent a default kit: the vendor passes `widgetInfo.textureKit` directly.
- Exact record type, required fields, nullability, and secret policy: unresolved pending generated docs and canonical record audit.
