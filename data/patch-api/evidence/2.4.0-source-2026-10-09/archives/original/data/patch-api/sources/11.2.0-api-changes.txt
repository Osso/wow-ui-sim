Patch 11.2.0 API changes

== Summary ==
* Added support for user-configurable font scaling to some parts of the UI, such as dialogs.
* Added support for the [TextLocale] variable expansion in TOC files, which will expand out to the client text locale (eg. "enUS").
* Added support for the [AllowLoadTextLocale ...] conditional line directive in TOC files, which allows restricting files to only load under specific client text locales.
* The API documentation has been expanded with annotations for functions that have security restrictions in place.
* The CreateFromMixins and Mixin APIs are now implemented as native functions. Previously, they were defined in Lua.
* Region:ClearAllPoints() now immediately invalidates the rect. Any measurement calculations relying on the previous rect should occur before calling ClearAllPoints.

== Breaking changes ==
* The StaticPopup_DisplayedFrames and STATICPOPUP_NUMDIALOGS global variables have been removed.
** Addons wanting to iterate over shown static popup dialogs should instead use StaticPopup_ForEachShownDialog.
* Various child key references on StaticPopup dialogs have been renamed.
** Addons should prefer to use the new accessor methods on StaticPopup frames to access regions such as Buttons and EditBoxes.
