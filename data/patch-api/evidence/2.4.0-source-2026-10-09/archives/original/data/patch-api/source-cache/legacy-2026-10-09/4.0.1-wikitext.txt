== Breaking changes ==
* Global variables '''this''', '''event''', '''arg1''', ..., are no longer available.
* UNIT_MANA, UNIT_ENERGY, UNIT_RAGE, UNIT_RUNIC_POWER, UNIT_FOCUS and UNIT_HAPPINESS events, as well as their UNIT_MAX* counterparts, no longer fire. {{api|t=e|UNIT_POWER}} and {{api|t=e|UNIT_MAXPOWER}} may be used instead.
* {{api|GetItemCooldown}} now only accepts numeric item IDs as its argument.
* Cancelling player buffs and temporary weapon enchants is now protected.
