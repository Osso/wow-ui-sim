Patch 12.0.7/API changes - Warcraft Wiki source snapshot from https://warcraft.wiki.gg/wiki/Patch_12.0.7/API_changes (searched 2026-07-06).

Resources: TOC 120007. Previous patch 12.0.5. Next patch 12.1.0.
Undocumented: Removed IMPORTANT from AuraFilters.

Blue posts / notes:
- Added GameTooltip_AddMoneyLine API using embedded atlases/MoneyFormatter; Blizzard removed usages of SetTooltipMoney.
- Unit identity: APIs restricting unit token types (UnitGUID, UnitAura, health/power APIs when called with PvP-restricted tokens) no longer raise Lua errors for unsupported tokens; return nil/default.
- ENCOUNTER_END includes additional payload: list of EncounterUnitStatus tables for all boss units engaged; fields creatureID, creatureName, remainingHealthPercent as non-secrets.
- C_EncounterEvents allows configuration of different colors for text warnings/timeline events; custom color for 5 seconds remaining signaled via ENCOUNTER_TIMELINE_EVENT_COLOR_CHANGED; color APIs accept alpha.
- Added C_UIFileAsset namespace: GetFileID(asset), IsKnownFile(asset), IsLooseFile(asset).
- Profiling APIs available to addons again: GetEventCPUUsage, GetFunctionCPUUsage, GetScriptCPUUsage.
- SimulateMouse APIs no longer carry taint when used, restricted to gamepad action and disallowed with forbidden/locked/script-inaccessible/protected mouse foci in combat.
- debugstack and debuglocals return secret values if current function or caller accessed secret value.
- Added secure action raidtarget option "set-unmarked" and /tm ~marker syntax.
- C_MythicPlus.GetRunHistory, GetWeeklyBestForMap, GetSeasonBestForMap now return CalendarTime structs instead of MythicPlusDate structs.
- GROUP_FORMED sent when player joins a follower dungeon or delve alone.
- AuraData.isFromPlayerOrPlayerPet true if aura came from player-controlled vehicle.
- Addons allowed to call C_UnitAuras.AddPrivateAuraAppliedSound during active M+ if player not in combat.
- Fixed secret value errors in SetFrameStrata.
- BNInviteFriend migrated to C_BattleNet.InviteFriend.
- Added DurationTextBinding script object type.
