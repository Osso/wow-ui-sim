Patch 1.14.1 API changes

== Summary ==
* Added C_Seasons to support Classic Era Season of Mastery.
* SharedTooltipTemplate and GameTooltipTemplate no longer inherit BackdropTemplate, see this section for solutions.
* The event trace tool now supports logging events while the frame is hidden. This option is disabled by default.
