## 2. Exact schemas and mechanical seed

12.0.0 top-level: `schema, patch, category_counts, direction_counts, occurrences, source`; schema `patch-api-source-register/v1`. `source` is an object with repository/product/boundary/base/snapshots/files/method/limitations. Rows have `direction, category, symbol, detail`; added has `after` (2554), removed has `before` (543), changed has both (313). Endpoint records are `category,value,metadata`; no per-row ID, page source_lines, prose, chronology or disposition.

12.0.5 top-level: `source, source_sha256, source_line_count, inventory_version, notes, counts, rows`; no top-level schema/patch. `source` is a plaintext file path, not an object. Its row fields are `id, section, kind, subject, change, source_lines, chronology, status` (chronological source status, NOT runtime proof). Atomic consolidated IDs encode section/subject/line; prose IDs encode date/line. 45 historical/proposed rows additionally have `superseded_by`; 317 have only the eight base keys. Page coverage separately binds the exact register bytes' SHA256.

**Mechanical endpoint seed is possible; exhaustive page ledger is not derivable from this register alone.** Use existing stable occurrence identity `direction:symbol`, preserve register order, bind SHA256 of raw register bytes, empty capabilities, every source_row audit-pending. Do not copy best-effort/evidence-required/exception-requested into page statuses, infer historical behavior or invent line numbers. Check uniqueness and exact equality with occurrence-manifest IDs before emitting. Direction distinguishes addition/removal of transient symbols; do not reassign ordinal IDs when sorting. Hash/reconciliation scope changes must be explicit when real page inventory arrives.

Sketch: `staging/patch-12-0-0/seed_coverage.py`. Preview: `staging/patch-12-0-0/12.0.0-page-coverage.sample-20.json` (20 rows, not a complete ledger). The sketch can emit all 3410 rows to a scratch destination without `--sample`; only the requested preview was emitted. No repo output was written.
