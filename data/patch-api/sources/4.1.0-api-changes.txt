Patch 4.1.0 API changes

== Breaking changes ==
* COMBAT_LOG_EVENT and COMBAT_LOG_EVENT_UNFILTERED have a new third parameter, hideCaster.
* Addons are now required to register the prefixes they want to receive SendAddonMessage messages for using  RegisterAddonMessagePrefix.

== Event changes ==
* COMBAT_LOG_EVENT and COMBAT_LOG_EVENT_UNFILTERED have a new third parameter, shifting existing parameters to the right.
* REMOVED END_REFUND, items no longer become unrefundable due to enchanting, etc.
* REMOVED HONOR_CURRENCY_UPDATE, honor now treated as ordinary currency
* REMOVED INSPECT_TALENT_READY, talent information available by default.
* REMOVED KNOWN_CURRENCY_TYPES_UPDATE
