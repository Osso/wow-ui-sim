Patch 11.1.7 API changes

== Summary ==
* Added a new C_AddOnProfiler.MeasureCall(func, ...) API for profiling individual function calls.
* Added a new C_AddOns.GetAddOnLocalTable(name) API that can retrieve the namespace table of an addon that opts-in to sharing it via a new AllowAddOnTableAccess TOC directive.
* Added a new table.create(arraySizeHint[, nodeSizeHint]) API that preallocates a table with a specified internal size.
