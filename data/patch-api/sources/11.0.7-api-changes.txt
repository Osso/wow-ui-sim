== Addon Profiling API ==

A new C_AddOnProfiler namespace has been added with functions for querying CPU performance metrics associated with addons.

The measurements recorded by this new profiler are always enabled and do not require the scriptProfile CVar to be enabled. As with existing profiling functions, these APIs only return values for user-installed addons and cannot be used to query the performance of secure Blizzard addons, nor can they be used to measure the performance of macro commands such as /run. Metrics are reset with UI reloads.

* C_AddOnProfiler.GetAddOnMetric(name, metric) : result - Returns a time value measured in milliseconds.
* C_AddOnProfiler.GetOverallMetric(metric) : result - As above, but returned value is the sum across all loaded addons.
* C_AddOnProfiler.IsEnabled() : enabled - Currently this function always returns true.

The metric parameter in the listed APIs corresponds to entries in Enum.AddOnProfilerMetric, listed below.
