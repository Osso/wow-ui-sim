# Garrison currency types

`C_Garrison.GetCurrencyTypes(garrisonType)` accepts a numeric garrison type and returns its primary and secondary currency IDs from the generated GarrType catalogue. A stored secondary value of zero is returned as zero. An unknown type returns no values. The query is published for Retail, PTR and WoW Forever.

The catalogue is generated by `python3 tools/gen_garrison_currency.py` from the GarrType CSV export for build 12.1.5.70391. The existing generated CurrencyTypes catalogue provides metadata for mapped currencies; owned quantity is independent of this lookup.
