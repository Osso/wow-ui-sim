# Forever Vanilla-style Group Finder inputs

`Blizzard_GroupFinder_VanillaStyle` (`## AllowLoadGameType: classic, camelot`) loads on Forever. Its file-load and `OnLoad` paths need the following surface.

- **Events.** VERIFIED (shipped Lua): Forever 70707 declares `LFG_LIST_ROLE_UPDATE` (`LFGListRolesDocumentation.lua:53`) and `LFG_LIST_SHOW_SEARCH` (`LFGListInfoDocumentation.lua:818`). `LFGListingFrame` and `LFGBrowseFrame` register them in `OnLoad`. Both are registerable on Forever.
- **`C_FriendList.GetWhoRaceFilters()`.** VERIFIED (shipped Lua): `FriendListDocumentation.lua:219` returns a non-nil array of `WhoFilter { name, ID }`. `Mainline/WhoList.lua:388` sorts the result in place during `LFGWhoListFrame` `OnLoad`. Each call returns a fresh array. UNVERIFIED (best guess): the rows are the 13 core playable races of the simulator's character-create race fixture, with its ChrRaces IDs (Human 1 … Draenei 11, Worgen 22, Pandaren 24). The native Forever roster is not established.
- **`C_LFGList.GetActivityInfoTable` level fields.** VERIFIED (shipped Lua): `GroupFinderActivityInfo` declares `minLevel`, `minLevelSuggestion` and `maxLevelSuggestion` non-nil on Retail, PTR, Mists and Forever. `LFGUtil_GetFilteredActivities` (`Blizzard_LFGVanilla_ParentFrame.lua:259`) compares them with the player level. INFERRED (best guess): `minLevel` and `minLevelSuggestion` are the supplied activity minimum level; `maxLevelSuggestion` is 0, which the consumer's `> 0` guard reads as no upper suggestion.

- **`C_LFGListRoles.GetRoles/GetSavedRoles/SetRoles`.** VERIFIED (shipped Lua): `LFGListRolesDocumentation.lua:10-45`; `LFGListingMixin:LoadSoloRolesOnStartup` reads the saved roles in `OnLoad` and writes them back through `SetRoles` (`Blizzard_LFGVanilla_Listing.lua:552-574`). `SetRoles` validates the `LFGRoles` table and fires the synchronous `LFG_LIST_ROLE_UPDATE`, which reloads the solo role buttons. `A_Admin.SetSavedLFGListRoles(roles)` supplies the roles saved by an earlier session. INFERRED (R-request pending): `SetRoles` also updates the saved roles; a character without saved roles starts with all three unset; `limitToClassRoles` has no effect because the simulator models all three roles as available.
- **Creation text fields.** VERIFIED (shipped Lua): `ClearCreationTextFields` and `CopyActiveEntryInfoToCreationFields` (`LFGListInfoDocumentation.lua:54-68`) act on the edit boxes that Blizzard registers with `StoreSecureReference` (`LFGListCreationName`, `LFGListCreationDescription`, `LFGListCreationVoiceChat`, Vanilla-style `LFGListingComment`); their text is protected from Lua. `CreateListing`/`UpdateListing` capture that text into the active entry's `name`/`comment`/`voiceChat`; `Clear` empties the fields; `Copy` writes the active entry back (no-op without one). INFERRED (R-request pending): the reference-name to entry-field mapping.
- **Search result members.** VERIFIED (shipped Lua): `GetSearchResultLeaderInfo`/`GetSearchResultPlayerInfo` return `LfgSearchResultPlayerInfo` or nothing (`MayReturnNothing`, `LFGListInfoDocumentation.lua:411-443,1017-1031`). Rows come from `A_Admin.SetPremadeListingMembers(searchResultID, members)`; a listing without rows returns nothing, which the Browse consumer guards (`Blizzard_LFGVanilla_Browse.lua:380-381,439-441`).
- **`C_LFGList.RequestAvailableActivities()`.** Undeclared in the Forever documentation; called by `Blizzard_LFGVanilla_ParentFrame.lua:55`. INFERRED (R-request pending): the reply is a deferred `LFG_LIST_AVAILABILITY_UPDATE`.
- **`C_FriendList.SendWho/SortWho`.** VERIFIED (shipped Lua): `FriendListDocumentation.lua:330-343,411-421`. `SendWho` validates the optional origin number and `SendWhoFilters` table, then routes the query like the legacy global (`src/c_api/who_routing.rs`). `SortWho(key, ascending?)` reorders `GetWhoInfo` and queues `WHO_LIST_UPDATE` (the Retail column header sorts without refreshing itself, `FriendsFrame.lua:2729-2733`). INFERRED: without `ascending`, the same key reverses and a new key sorts ascending; unknown keys keep the response order.
- **`C_Map.IsMapValidForNavBarDropdown(uiMapID)`.** VERIFIED declaration `MapDocumentation.lua:548-561`. INFERRED (R-request pending): a seeded map is valid when it lacks `UIMapFlag.DoNotShowOnNavbar` and is a continent or zone or has `ForceOnNavbar`; unknown maps are invalid.
- **`C_RaidLocks.GetRedirectedDifficultyID(mapID, difficultyID)`.** VERIFIED declaration `RaidLocksDocumentation.lua:11-24`. Returns a supplied redirect (`A_Admin.SetRaidDifficultyRedirects`), else `difficultyID`. INFERRED (R-request pending): the identity default.
